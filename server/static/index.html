RFC/x402 Protocol Flow

  1. Client probes endpoint with standard GET/POST.
  2. Server challenges with HTTP 402 + headers X-402-Recipient, X-402-Amount.
  3. Client signs & broadcasts native SOL transfer on Devnet.
  4. Client retries request with header X-402-Signature.
  5. Gateway verifies on-chain settlement & returns HTTP 200 OK.
